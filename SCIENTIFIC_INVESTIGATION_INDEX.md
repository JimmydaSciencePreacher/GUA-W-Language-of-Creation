# Scientific Investigation Index

This repository begins a new research sequence. No earlier investigation numbering or conclusions are presumed to be part of this sequence.

The first investigation will be numbered **001** and will begin from a clearly stated scientific question, with established scientific terminology and evidence retained alongside any GUA-W description.

## Indexing standard

Each entry will identify:
- investigation number and title;
- primary scientific discipline(s);
- central phenomenon or question;
- status (in progress, reviewed, or archived);
- link to the full investigation.

An investigation may connect to other fields, but cross-disciplinary links must state whether they identify the same mechanism, a comparable relationship, an analogy, or an unresolved resemblance.
